# MedalMC server banner

`medalmc-server-banner.png` (2000x667) is a server-list banner in Minecraft multiplayer style: logo, MOTD and player count.

To change the text (player count, IP, game modes), edit `source/banner.html` and render again:

```
cd source && node render.js
```

Fonts: Monocraft (SIL OFL 1.1, github.com/IdreesInc/Monocraft) and Fredoka (SIL OFL 1.1).
